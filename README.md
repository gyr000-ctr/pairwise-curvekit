# pairwise-curvekit

## 题面（可直接粘贴）

折线简化（Douglas-Peucker）。约束：首尾保留；容差越大点数不增；容差 0 原样返回；简化后最大偏差不超过容差；10 万点耗时不超过 400 ms 且不得递归爆栈（深度超过 1 万的输入要能处理）；并发简化同一输入结果一致；非法容差与非有限坐标要报错；不修改输入。验收：python -m pytest tests -q -k simplify。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 1 万点耗时
- 并发
- 容差边界
- 重复点
- 非有限坐标

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线）。
